# Welcome to Blog App

This is a blog platform built with **Next.js**, featuring user authentication, blog post management, and a clear user interface.

## Features

- **Create and manage blogs** - Write and publish your favourite blogs
- **User Profiles** - User pages with reading lists
- **Authentication** - Secure login and registration
- **Likes** - Show your support for the best blogs

## Getting started

To start exploring:

1. [Register](/register)
2. [Login](/login)
3. [Create a new blog](/blogs/new)
4. View [all blogs](/blogs) and add them to your personal [reading list](/me)
5. View other [users](/users)
